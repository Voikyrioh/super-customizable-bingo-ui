# super-customizable-bingo-ui — Guide pour Claude

## Lire en premier

1. **ARCHITECTURE.md** — carte du code (couches, flux principal, commandes).
2. **docs/INDEX.md** — point d'entrée des docs (adr, components).

## Rôle du repo

Interface Vue 3 de jeu bingo. Atomic design avec Tailwind CSS. État mockée en vue d'intégration API.

## Commandes essentielles

- Dev : `npm run dev`
- Tests : `npm run test`
- Build : `npm run build`
- Preview : `npm run preview`
- Lint : npx biome check --apply

## Skills obligatoires

- `/code-search` — localiser composants.
- `/dev-task` — implémentation.
- `/bugfix` — déboguer.
- `/doc-update` — maintenir docs/ à jour avec le code.
